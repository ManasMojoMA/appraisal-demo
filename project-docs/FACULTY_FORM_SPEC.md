# Faculty Self-Review Form Specification

## Faculty-facing form title
Faculty Annual Self-Review

## Faculty-facing introduction
This self-review form is intended to capture your annual contributions across service, research, academic delivery, and teaching innovation. Please provide clear, concise, and evidence-supported information. Where applicable, attach or link supporting documents such as reports, published papers, LMS screenshots, session plans, event reports, project documents, or official communication.

## Faculty-facing instructions
1. Enable only those categories where you have contributions to report.
2. Once a category is enabled, at least one entry must be completed.
3. You may add multiple entries under each category.
4. Every added entry must be fully completed before submission.
5. If an additional entry was added by mistake, delete it before submitting.
6. Evidence links should be accessible to the Program Office.
7. Save your draft regularly. The system will also autosave.
8. Final submission cannot be edited unless reopened by an authorized admin.
9. Submission after the deadline is not allowed unless an extension is approved.

## Category 1 — Service Contribution
### Description shown to faculty
Use this section to report responsibilities, institutional roles, industry engagement, initiatives, faculty development contribution, or other service activities undertaken during the appraisal period. Provide the role/task, your actions, and measurable impact wherever possible.

### Entry fields
| Field | Type | Required | Notes |
|---|---|---:|---|
| Position of responsibility | Text | Yes | Example: Coordinator, Committee Member, Faculty Mentor |
| Service contribution type | Select | Yes | Administrative Role, Industry Engagement, Institutional Initiative, Faculty Development, Other |
| Task / responsibility handled | Long text | Yes | What was assigned or initiated? |
| Action taken | Long text | Yes | What did you do? |
| Result / impact | Long text | Yes | Outcome, measurable benefit, student/faculty/process impact |
| Stakeholders benefited | Multi-select/Text | No | Students, faculty, school, industry, alumni, community |
| Start date | Date | Yes | Activity start date |
| End date | Date | No | Activity end/completion date |
| Evidence link/upload | URL/File | Yes | Report, email, MoU, photo, attendance, document |
| Remarks | Long text | No | Optional notes |

## Category 2 — Research Performance
### Description shown to faculty
Use this section to report research output completed, published, accepted, filed, presented, or funded during the appraisal period. Include accurate links and supporting evidence.

### Entry fields
| Field | Type | Required | Notes |
|---|---|---:|---|
| Type of research | Select | Yes | Journal Article, Book Chapter, Book, Case Study, Conference Paper, Funded Project, Patent, Industry Research, Other |
| Title of research | Text | Yes | Full title |
| Publication/completion date | Date | Yes | Publication, acceptance, filing, completion, or award date |
| Link of publication | URL | Conditional | Required for published/online work |
| Research document/evidence link | URL/File | Yes | Upload or link accepted manuscript/certificate/proof |
| Journal/publisher/conference/project/patent details | Text | No | Name, volume, issue, publisher, agency, patent office, etc. |
| DOI/ISBN/application number | Text | No | If available |
| Co-authors/collaborators | Text | No | Names and affiliations |
| Current status | Select | Yes | Published, Accepted, Presented, Filed, Completed, Ongoing, Submitted |
| Remarks | Long text | No | Optional notes |

| Remarks | Long text | No | Optional notes |

## Validation rules
- A disabled category is ignored during submission.
- An enabled category must contain at least one entry.
- The first entry is auto-created when a category is enabled.
- All mandatory fields in every entry must be completed.
- If a faculty member adds a second/third entry, that entry must also be complete.
- Empty additional entries must be deleted before submission.
- Evidence is required wherever marked mandatory.
- URLs must be valid and accessible.
- Date fields must fall within the configured appraisal cycle unless admin allows exceptions.
